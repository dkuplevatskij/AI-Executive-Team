# Согласования

Карточки действий уровня 3 (см. `.claude/rules/approval-policy.md`).

- `pending/` — ждут решения собственника;
- `approved/` — утверждены (статус APPROVED, после исполнения — EXECUTED);
- `rejected/` — отклонены.

Шаблон — `templates/approval-card.md`. Имя файла: `APR-ГГГГММДД-NN-кратко.md`.
Папка появляется вместе с первой карточкой.

Важно: файл со статусом APPROVED **не даёт агентам права** выполнить действие. Действия уровня 3
технически заблокированы; их выполняет собственник или подтверждает в окне прав Claude Code.
