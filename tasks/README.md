# Управленческие задачи

Поручения собственника и задачи команды директоров (не задачи разработки — те живут issues
в репозиториях продуктов).

- `backlog/` — принято, но не начато;
- `active/` — в работе;
- `completed/` — выполнено (файл переносится сюда, история хода работы сохраняется).

Шаблон — `templates/task.md`. Имя файла: `T-ГГГГММДД-NN-кратко.md`. Просроченные задачи
(поле `due` в прошлом, статус не `completed`) Chief of Staff выносит в ежедневную сводку.
