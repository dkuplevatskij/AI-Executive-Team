## Контекст для менеджера продукта

**Правила репозитория (`onfive/CLAUDE.md`).**
- Сократический принцип — основа продукта: ИИ никогда не даёт готовых ответов, ведёт подсказками; полное решение — только после 2–3 попыток ученика и его явной просьбы. Правки промптов и режимов не должны это ломать. Доклады: ИИ даёт план и помогает формулировать, не пишет весь текст за ученика (режим «Черновик» — для старших классов).
- Принцип работы: всегда кратчайший и самый простой путь; озвучить простой вариант и оценку времени до начала.
- Секреты только в `.env`, не в чат и не в git; перед push проверять `git diff --cached` на ключи.
- Дизайн: Apple Cupertino, WCAG AA, тач-цели от 44 px (`onfive/PRODUCT.md`).
- Документ `CLAUDE.md` частично устарел: описывает `voice.ts`, `stats.ts`, Whisper, Telegram Mini App, которых в коде нет (аудит п. 10). Источником истины о коде считать аудит и сам код.

**Инфраструктура.** Один сервер Timeweb обслуживает пять сайтов, в том числе RELTA и OnFive; общий Caddy. Правила работы с сервером (бэкап и проверка конфига перед reload, не удалять смонтированные папки, не ставить nginx) — в `ai-mentor/CLAUDE.md`, раздел «Инфраструктура сервера». Агенты центра к серверам не обращаются (`.claude/rules/security-policy.md`); цифры выгружает собственник.

**Наблюдения по GitHub (02.11.2026).** Закрытые issues `error-watch` (8 и 13.10.2026) показывали перезапуски `onfive-app` и ошибки БД с ролью `supabase_admin` — следы прежней схемы. Issue #42 «Проверка кода: октябрь 2026 — найдена серьёзная проблема» закрыта, содержание не изучалось. Поле `merged` в списке PR возвращается `false` для всех, хотя коммиты в `main` ссылаются на их номера (#63–#68) — статус слияния по PR API не подтверждён, ориентир — история `main`.
