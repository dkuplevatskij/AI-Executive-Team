## Контекст для менеджера продукта

**Правила репозитория (`ai-mentor/CLAUDE.md`, кратко)**
- Иконки только через `Icons.xxx`; эмодзи нигде нельзя. UI, письма и лендинги — только по-русски (допустимы AI, KPI, CRM).
- Перед коммитом `npx tsc --noEmit` (EXIT=0); при правках `services/` — `npm run typecheck:wa`. Перед push — `npx next build`, но не `npm run build` (тот делает `prisma db push --accept-data-loss`).
- Изменили `schema.prisma` — обязательна миграция в `prisma/migrations/`, идемпотентная; новые поля optional.
- Перед новыми страницами и крупными UI-компонентами — макет и согласование с собственником; UI без согласования дизайна не деплоится.
- Секреты только в `.env`, не коммитить; каждый вызов Claude — через `enforceAndConsume()` и запись в `LlmUsage`.
- Деплой: автодеплой по мержу в main (`deploy.yml`); если Actions недоступны — `./infra/deploy-remote.sh` с ноутбука собственника. Мы деплой не выполняем.

**Инфраструктура**
- Сервер Timeweb обслуживает пять сайтов (relta.tech, agent-hunter.ru, ainalog.pro, onfive.pro, rexeed.ru) через один Caddy; ошибка в конфиге роняет все сайты. Узел в Амстердаме тоже общий (Caddy, rexeed, vpn-sub, `/opt/relta-wa`). Любое вмешательство в инфраструктуру — только собственник (уровень 3).
- Сертификат relta.tech действителен до 05.01.2027 (проверка 02.11.2026).
