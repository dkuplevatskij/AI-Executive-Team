**Правила репозитория (CLAUDE.md, кратко):**
- Проверки: `npm run build` → `npm test` (smoke jsdom + content), `npm run typecheck`, `npm run test:server` (нужны dist/ и Postgres; `npm run db:up`).
- Состояние `S` меняется только через `mutate(fn)`, любое изменение кончается `save()` — единственная точка сохранения и отправки на сервер. В localStorage в обход `save()` не писать.
- Прогресс хранит НОМЕРА ответов: варианты не переставлять, вопросы вставлять только в конец модуля; страж — `test/answers.snapshot.json`.
- `calcState` — чистая функция; итоги по курсу из `CATALOG`, не из длины списков (без подписки списки неполные).
- Таблицы: правка `server/schema.ts` → `npm run db:generate` → миграция в `server/migrations` (коммитить). Сервер: только стираемый TS, импорты с расширением `.ts`.
- Вход: без `consent: true` вход не начинается (152-ФЗ); `PD_POLICY_VERSION` менять вместе с текстом политики.
- `sandbox/.env.lab` — учебный ЛОЖНЫЙ секрет, не переименовывать в `.env`. Секреты — только в окружении.
- CI не запускается при изменении только README.md, CLAUDE.md, docs/**.
- Аудитория — Россия: оплата только российским провайдером (не Stripe), хостинг и база в РФ.

**Решения владельца (docs/PLAN.md:14-19, утверждён 13.10.2026).** Платят пользователи из России. Бесплатно: модули 00–03, лабы 1–2, справочник. Платно: модули 04–12, лабы 3–8, остальные упражнения/сценарии, входной тест, драйл, экзамен, сертификат. В команде каждый платит сам; команда = группа, рейтинг, отчёт админу.
