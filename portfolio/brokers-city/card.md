## Контекст для менеджера продукта

**Состояние GitHub на 02.11.2026 (сверено с аудитом, расхождений нет):** последний коммит в `main` — 08.10.2026 16:20 UTC (слияние PR #214, обновление next/sharp/proxy-addr); открытых PR и issues нет; две ветки (`main`, `backup-projects-dk`); последний CI — зелёный (запуск №646, 08.10).

**Ключевые правила репозитория (`DK/CLAUDE.md`):**
- Сервер — единственный источник истины, клиент экономику не считает и `@metropolis/shared` не импортирует.
- Деньги меняются только проводкой `post()`; исправление — встречная проводка, не UPDATE. Новый денежный обработчик приходит с тестом.
- Проверка в той же транзакции, что и запись; порядок замков: объект, потом компания.
- Механика появляется в `tools/balance-sim` раньше, чем в `apps/worker`/`apps/api`. Числа в JSON (`database/`, `economy/`) не хранятся константами в симуляторе; правка баланса требует согласия автора и прогона `--compare --runs 25`.
- Идентификаторы не переводятся, экран целиком по-русски; подсказки только через «?» (`<Hint>`, `<Term>`).
- Согласие человека нужно на слияние в `main`, выкладку, удаляющие миграции, правку баланса, смену состава MVP. Слияние — merge-коммитом.
- Эти правила — для сессий разработки продукта; команда директоров код не меняет (`.claude/rules/github-policy.md`).

**Устаревшее в самом репозитории (аудит п. 10):** `DK/CLAUDE.md` ссылается на несуществующую ветку и на «нет минут Actions до 1 октября» (CI в октябре работал); `ROADMAP §6` расходится с `ADR-021` (хостинг выбран); README 6 строк.
