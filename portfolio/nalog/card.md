## Контекст для менеджера продукта

**Правила репозитория (nalog/CLAUDE.md, на main 04.11.2026).**
- Команды: `pnpm dev | build | check | test | format | db:push`. Тесты — Vitest, рядом с кодом (`*.test.ts`). Весь UI и тексты — на русском, валюта ₽ без копеек.
- Расчёты налогов — чистые функции в `taxCalculator.ts`, без побочных эффектов.
- Налоговая специфика: НДФЛ при продаже — 13% до 2,4 млн и 15% свыше; пятиступенчатая шкала 13–22% к продаже недвижимости не относится; сроки владения 3 и 5 лет (в 10 регионах сокращённый срок); вычеты 1 млн ₽ (жильё) и 250 тыс. ₽ (нежилое); правило кадастровой стоимости с коэффициентом региона продавца (0,7, в 16 регионах 1,0); нерезиденты и иноагенты — 30%; семейная льгота (6 условий); расчёт по членам семьи. Законопроекты 2027 года не приняты. Регрессионные тесты ревью — `taxCalculator.review.test.ts`; последняя сверка с законом — 03.11.2026.

- Политика моделей: по умолчанию claude-sonnet-4-6, Opus — только по прямой просьбе.
