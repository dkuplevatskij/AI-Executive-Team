## Контекст для менеджера продукта

**Правила репозитория (nalog/CLAUDE.md).**
- Команды: `pnpm dev | build | check | test | format | db:push`. Тесты — Vitest, рядом с кодом (`*.test.ts`). Весь UI и тексты — на русском, валюта ₽ без копеек.
- Расчёты налогов — чистые функции в `taxCalculator.ts`, без побочных эффектов.
- Налоговая специфика: НДФЛ при продаже — 13% до 2,4 млн и 15% свыше; пятиступенчатая шкала 13–22% к продаже недвижимости не относится; сроки владения 3 и 5 лет; вычеты 1 млн ₽ (жильё) и 250 тыс. ₽ (нежилое); правило 70% кадастровой стоимости; нерезиденты и иноагенты — 30%; семейная льгота (6 условий). Законопроект 2027 года не принят.
- Для проверки расчётной логики в репозитории есть агент `tax-advisor` (`.claude/agents/tax-advisor.md`); последняя сверка с законом — 05.10.2026.
- Политика моделей: по умолчанию claude-sonnet-4-6, Opus — только по прямой просьбе.
- Безопасность: секреты только в `.env`, не коммитить `.env`, логи, ключи.
- Диагностика прода: сначала собрать контекст одним пакетом команд, гипотеза до правок, общий Caddyfile вслепую не править.

**Инфраструктура.**
- Сервер общий с RELTA: один Caddy (`infra-caddy-1`) обслуживает пять сайтов, ошибка в конфиге роняет все (ai-mentor/CLAUDE.md). Блок NAlog описан в `deploy/nalog.caddy` и перечисляет `ainalog.pro` и `www.ainalog.pro`.
- `www.ainalog.pro` при проверке 02.11.2026 отдавала Vercel (кэш обновлён 31.10.2026), мастер «из 11 шагов» против 12 в CLAUDE.md. Основной `ainalog.pro` из облачной сессии не проверен (прокси 403). В CLAUDE.md RELTA сказано не менять DNS чужого домена ради ошибки в логе и сначала выяснить, кто пользуется адресом.
- Управляющий центр доступа к серверам не имеет; цифры из Umami и баз выгружает собственник.
