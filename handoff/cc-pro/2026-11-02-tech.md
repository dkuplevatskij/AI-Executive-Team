### C-1. Платный контент отдаётся всем без проверки доступа — высоко (до любого запуска)
- **Что не так:** `src/paid/*.js` собирается в ту же страницу, сервер отдаёт `dist/index.html` без проверки
  (`server/app.ts`). Любой, кто открыл страницу, получает модули 04–12.
- **Что сделать:** собирать платный контент отдельно и отдавать с сервера только при активном доступе
  (по `docs/PLAN.md` — после подписки); бесплатная часть остаётся статической.
- **Готово, когда:** без доступа платные модули не приходят в браузер ни в каком виде; тест.

### C-2. Нет текста лицензии исходного курса — средне

  (только ссылка в футере, `src/js/90-render.js:23`).
- **Что сделать:** добавить текст MIT с указанием авторства исходного курса.

### C-3. Нестрогая версия Better Auth — низко
