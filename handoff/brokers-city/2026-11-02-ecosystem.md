## Задачи

- **Что сделать:** 2–3 варианта для собственника, каждый в 3–5 строках: где игрок видит продукты
  (экран «об игре», подвал клиента, онбординг, событие или награда в игре), что видит (RELTA — CRM для
  агента, NAlog — налог с продажи объекта, Agent Skills Pro — тренировки переговоров с ИИ-клиентом),

- Не трогать баланс, экономику и игровые числа.
- **Готово, когда:** собственник выбрал вариант; после этого — отдельный PR по выбранному.
