## Что продаём
Две разовые покупки без аккаунта, по конкретному расчёту, через Robokassa:

| Покупка | Цена | Что получает человек |
|---|---|---|
| «PDF-отчёт» | 190 ₽ | PDF по своему расчёту |
| «PDF + AI-разбор» | 290 ₽ | PDF и AI-разбор этого расчёта |

AI-разбор отдельно не продаётся. Расчёт в мастере остаётся бесплатным.

## Задачи (по порядку работы)

### NP-1. Заказы и оплата через Robokassa — критично
- **Сейчас:** оплаты нет; на экране результата заглушки «Доступно после оплаты»
  (`client/src/components/TaxResults.tsx:293-295`).
- **Что сделать:** таблица заказов (вид покупки, сумма, статус, снимок данных расчёта, email для чека, даты
  создания и оплаты, одноразовый токен доступа). Цены — константами на сервере, клиент сумму не передаёт.
  Создание заказа → переход на оплату Robokassa с подписью → Result URL: проверка подписи паролем №2 и суммы,
  повторное уведомление не меняет оплаченный заказ → страницы успеха и отказа. Чек по 54-ФЗ — в настройках
  магазина под форму деятельности собственника (её сообщит собственник). Таблица — через миграцию drizzle
  (`drizzle/`), а не `push`.
- **Готово, когда:** тестовая оплата в тестовом режиме Robokassa переводит заказ в «оплачен» ровно один раз;
  поддельный или повторный Result URL не меняет заказ; сумма берётся только с сервера.
- **Проверка:** тесты на подпись, сумму, повтор и чужой заказ; один ручной прогон в тестовом режиме.

### NP-2. Выдача PDF только по оплаченному заказу — критично
- **Сейчас:** PDF собирается в браузере (`client/src/components/ReportModal.tsx:17-39`, `lib/reportHtml.ts`,
  html2pdf.js), окно отчёта нигде не подключено; без проверки оплаты его можно получить бесплатно.
- **Что сделать:** после оплаты человек попадает на страницу своего заказа по токену и скачивает PDF по снимку
  расчёта из заказа. Предложи собственнику в плане способ, при котором без оплаченного заказа отчёт с нашего
  сайта не получить: например, сервер отдаёт данные отчёта или сам PDF только по оплаченному токену. Ссылка
  на заказ живёт не меньше 30 дней и приходит на email вместе с чеком, если Robokassa это позволяет.
- **Готово, когда:** без оплаты PDF не скачивается ни из интерфейса, ни прямым запросом к серверу; после оплаты
  скачивается со страницы заказа и повторно по ссылке.

### NP-3. AI-разбор только по оплаченному заказу — критично
- **Сейчас:** AI выключен общим флагом `AI_ANALYSIS_PAID_ONLY` (`server/routers/aiRouter.ts:7,144`), обработчик
  открыт всем (`publicProcedure`, строка 138), лимита вызовов нет; ответ — 2–4 абзаца общего текста.
- **Что сделать:**
  - вместо общего флага — проверка заказа «PDF + AI-разбор» в статусе «оплачен»;
  - один заказ — один успешный вызов модели; результат сохраняется в заказе, повторный показ — из сохранённого;
  - лимит частоты на обработчик;
  - структура ответа: «что можно упустить и сколько это стоит» с суммами из расчёта; проверка ответа перед
    выдачей — суммы и статьи НК сверяются с расчётом, при расхождении ответ не показывается, повтор;
  - в запрос по-прежнему уходят только числа и признаки расчёта, без имени, адреса, кадастрового номера и
    email — закрепить тестом;
  - включение AI в проде — отдельной переменной окружения, по умолчанию выключено; включает собственник
    (см. ниже).
- **Готово, когда:** без оплаченного заказа «PDF + AI» обработчик отказывает; повторные запросы по одному заказу
  не вызывают модель второй раз; тест подтверждает отсутствие персональных данных в запросе.

### NP-4. Содержание отчёта, за которое платят — высоко
- **Что сделать (с `tax-advisor`):** статьи НК рядом с выводами; сроки подачи (30 апреля, уплата до 15 июля)
  для этого случая; список документов для 3-НДФЛ и подтверждения расходов; сравнение «вычет 1 млн / 250 тыс
  или подтверждённые расходы» с обеими суммами; дата правил (сверка 05.10.2026) и пометка, что законопроект о
  шкале 13–22% с 2027 года не принят. Оговорку «не является налоговой консультацией» — в начало отчёта, а не
  только в подвал. Убрать эмодзи из отчёта (`lib/reportHtml.ts:179,192,200`). AI-разбор — отдельный раздел PDF
  для покупки за 290 ₽.
- **Готово, когда:** отчёт содержит всё перечисленное; `tax-advisor` подтвердил тексты.

  передаются обезличенные данные. Без этого продажу «PDF + AI» не открывать.
