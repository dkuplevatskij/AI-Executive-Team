## Задачи

### NE-1. Блок «Продукты для риелторов и агентств» — высоко
- **Где:** (1) на экране результата расчёта — под результатом, не перекрывая будущий платный отчёт;
  (2) отдельная секция в подвале каждой страницы (короткая версия: названия-ссылки).
- **Что внутри (тексты — черновик, собственник может поправить):**
  | Продукт | Текст | Ссылка |
  |---|---|---|
  | RELTA | ИИ-платформа агента и агентства: сделки и воронка, разбор звонков, KPI, тренажёр переговоров | https://relta.tech |
  | Agent Hunter | Найм риелторов: тест и голосовое AI-интервью кандидата, отчёт с баллом для HR | https://agent-hunter.ru |
  | Agent Skills Pro | Продвинутое обучение и тестирование агентов | лендинга пока нет — карточка с пометкой «Скоро», без ссылки |
  | Студия ReXeeD | Создатель этих платформ: внедряет AI в бизнес-процессы | https://rexeed.ru |
- **Готово, когда:** блок виден на результате и в подвале на телефоне и компьютере; не мешает мастеру расчёта.

### NE-2. Метки источника на всех ссылках — высоко
- **Что сделать:** каждая ссылка с UTM: `utm_source=nalog&utm_medium=ecosystem&utm_campaign=<result|footer>`
  (для ReXeeD — `utm_medium=credit` в подписи, см. NE-3). Ссылки открываются в новой вкладке.
- **Зачем:** без меток не посчитать, сколько людей NAlog привёл в другие продукты.

### NE-3. Подпись «Платформа создана студией ReXeeD» — средне
- **Где:** подвал всех страниц, рядом с дисклеймером. Ссылка:
  `https://rexeed.ru/?utm_source=nalog&utm_medium=credit`.

### NE-4. Учёт кликов в аналитике — средне
- **Что сделать:** события Umami (уже подключена, `client/index.html:44-45`) на клик по каждой карточке
  блока: имя события `ecosystem_click`, параметры `product` и `place`.
- **Готово, когда:** в Umami видны клики по продуктам за день.

### NE-5. Агентство не путает калькулятор с консультацией — низко
- **Что сделать:** блок оформить как «Другие продукты» и не размещать между расчётом и дисклеймером
  «не налоговая консультация».
