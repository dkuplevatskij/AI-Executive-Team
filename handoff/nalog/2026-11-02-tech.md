## Задачи (по убыванию важности)

### N-1. Локальный docker-compose займёт порты общего сервера — критично
- **Что не так:** `docker-compose.yml` публикует nginx на 80/443. На сервере порты держит общий Caddy
  для пяти сайтов.
- **Почему важно:** случайный `docker compose up` этим файлом на сервере положит все пять сайтов.
- **Что сделать:** убрать публикацию 80/443 из локального compose (или переименовать в явно локальный),
  оставить прод только на `docker-compose.vps.yml`; убрать устаревшие `deploy/nginx.conf`, `deploy/setup.sh`
  — после согласия собственника.
- **Готово, когда:** ни один compose-файл в репозитории не публикует 80/443.

### N-2. Выкладка без тестов, типов и сборки — высоко
- **Что не так:** `.github/workflows/deploy.yml` выкатывает каждый push в main без `pnpm check`, тестов и сборки.
- **Что сделать:** перед деплоем — `pnpm check`, `pnpm test`, `pnpm build`; деплой только при зелёных.
- **Готово, когда:** при красном тесте деплой не стартует.

### N-3. Схема БД на проде меняется без миграций — высоко
- **Что не так:** деплой выполняет `drizzle-kit push`, папка `drizzle/migrations/` пустая.
- **Что сделать:** перейти на `drizzle-kit generate` + применение миграций; базовая миграция по текущей схеме.
  Важно перед монетизацией: появятся таблицы пользователей и платежей.
- **Готово, когда:** деплой применяет миграции, `push` в проде не используется.

### N-4. Квоту DaData можно выжечь извне — высоко
- **Что не так:** публичные эндпоинты подсказок без ограничения частоты (`server/routers/addressRouter.ts:208`,
  `server/routers/egrnRouter.ts:243`).
- **Что сделать:** ограничение частоты по IP (и общий суточный потолок), кэш ответов.
- **Готово, когда:** при превышении лимита возвращается 429; тест.

### N-5. Node 20 в Dockerfile — средне
- **Что не так:** `Dockerfile` на Node 20; поддержка Node 20 закончилась 30.04.2026.
- **Что сделать:** перейти на Node 22 LTS, прогнать тесты и сборку.

### N-6. Две версии сайта: сервер и Vercel — средне
- **Что не так:** `www.ainalog.pro` отдаёт Vercel (мастер «из 11 шагов», обновлено 31.10.2026), а прод
  выкатывается на сервер (`deploy/nalog.caddy` обслуживает оба адреса). В репозитории остались `vercel.json`,
  `api/index.js`, `server/vercel/handler.ts`.
- **Что сделать:** выяснить, что подключено к Vercel (проект, автодеплой из какой ветки); подготовить
  собственнику вариант: убрать Vercel-конфигурацию и перевести www на сервер. DNS меняет собственник.
- **Готово, когда:** оба адреса отдают одну и ту же версию с сервера.

### N-7. Документация и мусор — низко
- **Что не так:** дубль `CLAUDE (2).md` с несуществующими файлами; `CLAUDE.md` упоминает удалённый
  `TaxForm.tsx`; `client/src/lib/taxCalculator_ndfl_new.txt`; два lock-файла (npm и pnpm); нет `.env.example`
  (на него ссылается `vps-deploy.sh`); шаблонные TODO Manus.
- **Что сделать:** привести в порядок; удаление файлов — после согласия собственника.
