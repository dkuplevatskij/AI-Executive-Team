# Задания для сессий разработки продуктов

Технические проблемы продуктов управляющий центр сам не исправляет и не заводит на GitHub
(решение собственника D-010). Он пишет задание, а собственник пересылает его в сессию Claude Code,
которая отвечает за конкретный проект.

## Как пользоваться

1. Откройте файл продукта ниже, скопируйте его целиком.
2. Вставьте в сессию разработки этого продукта (сессия с его репозиторием).
3. Когда задачи сделаны (или часть), скажите AI CEO: «<продукт>: сделаны задачи …» — статус обновится
   здесь, а Head PM обновит карточку продукта.

Раздел «Что делает собственник» в каждом файле — действия, которые сессия разработки выполнить не может:
смена паролей и ключей, настройки на сервере, DNS, решения.
