# Достоверность данных

Главное правило: **система не выдаёт предположение за факт.** Ошибка в цифре, на которую
опирается решение собственника, хуже, чем честное «данных нет».

## Метки

Каждое утверждение в отчёте, карточке и рекомендации относится к одному виду:

| Метка | Когда | Пример |
|---|---|---|
| `[ФАКТ: источник]` | подтверждено файлом, коммитом, PR, выпиской, словами собственника | `[ФАКТ: src/lib/pricing.ts]` Agent — 990 ₽ |
| `[ВНЕШНИЙ: источник, дата]` | данные из интернета или чужих отчётов | `[ВНЕШНИЙ: сайт конкурента, 02.11.2026]` |
| `[РАСЧЁТ: методика]` | вычислено из фактов; методика указана | `[РАСЧЁТ: MRR = Σ активных подписок × цена]` |
| `[ПРЕДПОЛОЖЕНИЕ]` | вывод без прямого подтверждения | — |
| `[РЕКОМЕНДАЦИЯ]` | предложение команды | — |
| `[НА УТВЕРЖДЕНИИ: APR-…]` | ждёт решения собственника | — |

В таблицах допустимо указать источник в отдельной колонке вместо метки.

## Запреты

- Не заполнять поле предположением. Нет данных — «Нет подтверждённых данных» или «Не заполнено».
- Не считать отсутствующее нулём: «выручка: нет данных» ≠ «выручка: 0 ₽».
- Не считать показатель, если нет исходных данных для него. CAC без расходов на привлечение,
  LTV без оттока, Churn без истории подписок не считаются — пишется, каких данных не хватает.
- Не смешивать **выручку** (начислено за период), **поступления** (деньги на счёте) и
  **прибыль** (выручка минус расходы).
- Не путать деньги продукта и деньги клиентов продукта: агентское вознаграждение в Агроконтуре
  или экономика агентств в RELTA — это данные клиентов, не выручка портфеля.
- Цена в коде ≠ цена, по которой реально платят. Тариф в коде — факт о продукте, не о выручке.

## Свежесть

У каждой цифры есть дата. Карточка продукта хранит дату последнего обновления; данные старше
30 дней в отчёте помечаются «(устарело, на ДД.ММ.ГГГГ)». Внешние рыночные данные — всегда с
датой исследования и ссылкой.

## Противоречия

Если два источника расходятся (финмодель и код, лендинг и код, два директора), это не
усредняется, а выносится в отчёт как противоречие с обоими источниками. Разбирается CDO.
