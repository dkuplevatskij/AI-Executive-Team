## Известные ограничения проверок

- Режим обхода прав (`--dangerously-skip-permissions`): не проверено — фильтр безопасности облачной
  сессии не разрешает такой запуск. Проверить вместе с собственником на этапе 6.
- Вложенная тестовая сессия Claude Code не получает подключение к GitHub — проверки GitHub выполнены
  из основной сессии.
- В тесте №10 шаг проверки карточки CDO не выполнялся (проверялась механика подключения); CDO проверен
  на восьми основных карточках.
- Замки репозитория действуют на сессии, запущенные в папке репозитория. Сессия, запущенная в другой
  папке (как сессия внедрения 02.11.2026), ими не ограничена — изменения такой сессии приходят к
  собственнику только через PR.
