**Платформа Agent Skills Pro для Департамента коммерческой недвижимости**

> Черновик. Клиенту отправляет собственник. Места в квадратных скобках заполняются перед отправкой.

Agent Skills Pro — платформа, на которой брокеры тренируют переговоры с ИИ-клиентом, а руководитель видит уровень каждого брокера по одной шкале. Департамент получает закрытое пространство: доступ есть только у ваших сотрудников, данные отделены от других организаций.

## Что получает департамент

- **Тренировки по коммерческой недвижимости:** торговая, офисная и индустриальная. Клиент каждый раз новый: ИИ задаёт ему бюджет, возражения и скрытые мотивы.
- **Пять типов тренировок, пять уровней сложности:** свободная тренировка, холодный звонок, работа с возражениями, презентация объекта, переговоры с продавцом.
- **Разбор после каждой тренировки:** оценка по критериям и по достижению цели, с цитатами из диалога. Брокер сначала оценивает себя сам, затем видит оценку системы.
- **Тесты и экзамены:** банк вопросов, таймер, проверка открытых ответов, сертификат в PDF.
- **Кабинет руководителя и начальника отдела:** отделы, брокеры, история тренировок, расхождение самооценки с оценкой системы, расход на ИИ.
- **Свои сценарии:** руководитель добавляет сценарии под задачи департамента; черновики готовит ИИ, публикует только человек.

В плане развития: тренажёр техник продаж (СПИН, скрипты), отчёты по команде, голосовые звонки. Сроки сообщим отдельно.
