# AI Executive Team

Управляющий центр портфеля SaaS-продуктов: виртуальная команда директоров внутри Claude Code.
Главная сессия Claude Code в этой папке — AI CEO. Директора (CFO, CTO, CPO и другие) —
субагенты, которых AI CEO вызывает по задачам. Отдельного приложения, сайта или базы данных нет:
всё хранится в этом репозитории файлами и в GitHub.

## Как начать работу

**В облаке (claude.ai/code).** Откройте новую сессию и выберите репозиторий `ai-executive-team`.
Чтобы команда видела продукты, добавьте в сессию и их репозитории.

**На своём компьютере (Mac).** В Терминале, один раз:

```bash
git clone https://github.com/dkuplevatskij/ai-executive-team.git && cd ai-executive-team && claude
```

При первом запуске Claude Code спросит, доверяете ли вы этой папке, — ответьте «да».
Без этого не действуют разрешения из `.claude/settings.json` (запреты и замки действуют в любом
случае). Нужен `python3` — на Mac он ставится вместе с инструментами разработчика
(`xcode-select --install`).

## Безопасность — коротко

- Агенты **не могут**: сливать PR, писать в `main`, удалять файлы, заходить на серверы, запускать
  выкладку, отправлять письма и сообщения, менять код продуктов без вашего подтверждения, менять
  собственные права. Это запрещено технически — замком `.claude/hooks/guard.py` и правилами
  `deny` в `.claude/settings.json`, а не только текстом.
- Каждое изменяющее и каждое заблокированное действие пишется в `logs/actions.jsonl`.
- Проверить замки самому: `python3 tests/test_guard.py` (из папки репозитория).

Подробнее: `.claude/rules/approval-policy.md`, `.claude/rules/security-policy.md`.
