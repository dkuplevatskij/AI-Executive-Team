# Аудит портфеля — этап 1 «Инвентаризация»

Дата: 2026-11-02. Подготовил: AI CEO (главная сессия) по отчётам четырёх агентов-аудиторов.
Метод: только чтение — код репозиториев, история git, GitHub API (PR, issues, ветки, запуски Actions). Боевые сайты из облачного контейнера недоступны (сеть ограничена), поэтому статус определён по коду и запускам деплоя, а не по живому сайту. Подробные отчёты по продуктам — в соседних файлах.

Обозначения: **факт** — подтверждено кодом или GitHub; **вывод** — заключение аудитора; **нет данных** — в репозиториях этого нет.

## 1. Краткое резюме

1. В портфеле 8 продуктов: 5 запущенных и 3 в разработке.
2. **Ни у одного продукта нет подтверждённой выручки в данных** (факт по коду). Онлайн-оплата не работает нигде:
   - у RELTA и Agent Hunter платные тарифы включаются вручную после оплаты по счёту;
   - у OnFive оплата через CloudPayments написана, но не запущена по юридическим причинам;
   - у остальных оплаты нет.
   Финансовый анализ «на реальных данных» возможен только на ваших цифрах: банковская выписка, выставленные счета, счета за серверы и модели.
3. **Четыре из пяти запущенных продуктов работают на одном сервере** (Timeweb) за одним Caddy: RELTA, Agent Hunter, NAlog, OnFive. Это единая точка отказа (факт: `ai-mentor/CLAUDE.md`, деплой-конфиги).
4. **Три продукта выкатываются в прод без запуска тестов:** NAlog, Agent Hunter, OnFive. У RELTA тесты идут только при выкладке, на PR проверок нет (факт: workflow-файлы).
5. **Персональные данные уходят зарубежным ИИ-моделям** в RELTA, Agent Hunter (голос кандидатов) и OnFive (переписка несовершеннолетних). Это риск по 152-ФЗ (вывод).
6. Активная разработка за последние 10 дней идёт в трёх продуктах: RELTA, Agent Hunter, AgentScore. Агроконтур, OnFive, NAlog и Claude Code PRO стоят с 22–26.10, Brokers City — с 08.10 (факт: даты коммитов).
7. Продукты для агентств недвижимости пересекаются: AgentScore (тренажёр), тренажёр внутри RELTA и Agent Hunter (оценка кандидатов). Имя «AgentScore» уже носил старый MVP Agent Hunter (факт).

## 4. Проблемы, требующие внимания (по убыванию важности)

Только находки. Исправление — решение владельца и команды каждого продукта; управляющий центр репозитории продуктов не меняет.

1. **Безопасность — проверить в первую очередь**
   - Agent Hunter: проверка «суперадмин» пускает роль `admin` (`server/routers.ts:48–52`). Если эту роль получают сотрудники агентств, у них доступ к суперадминке. Нужно выяснить, кому она выдаётся.
   - Агроконтур: в `docker-compose.yml` пароли и `JWT_SECRET_KEY` по умолчанию (`change-me-in-production`), приложение с ними стартует. Переопределены ли они на проде — нет данных.
   - AgentScore: в истории git лежит старый `backend/.env` (коммит `ca472df`). Если эти ключи где-то использовались, их надо считать раскрытыми и заменить.
   - Claude Code PRO: платный контент отдаётся любому, кто открыл страницу.
   - NAlog: эндпоинты DaData без ограничения частоты, квоту ключа можно выжечь извне. Кроме того, локальный `docker-compose.yml` занимает порты 80/443: запуск на общем сервере положит все пять сайтов.
   - Agent Hunter: документация API (`/api-docs`) открыта публично.
2. **Надёжность**
   - Общий сервер для четырёх продуктов.
   - Выкладка без тестов в трёх продуктах.
   - У NAlog и Agent Hunter миграции базы не ведутся: схема меняется на лету (`drizzle-kit push`, таблицы создаются кодом).
   - Бэкапы OnFive хранятся на том же сервере, у остальных нет данных.
3. **Деньги:** ни выручка, ни платежи не учитываются в базах. Расход на ИИ не учитывается в 4 продуктах, где ИИ используется.
4. **Право:**
   - трансграничная передача персональных данных (RELTA, Agent Hunter, OnFive);
   - у OnFive не заполнена оферта, нет уведомления в РКН;
   - товарный знак «Claude» в названии Claude Code PRO;
   - названия Brokers City не проверены.
5. **Портфель:**
   - три продукта для агентств недвижимости пересекаются, есть конфликт имени AgentScore;
   - в финмодели и на лендингах RELTA цены расходятся с кодом.
6. **Технический долг:**
   - мусор в корне RELTA и Agent Hunter, наследие Manus;
   - десятки смерженных, но не удалённых веток: RELTA — 48, Agent Hunter — 24, Агроконтур — 9;
   - файлы `CLAUDE.md` расходятся с кодом (RELTA, OnFive, NAlog, Brokers City, Агроконтур).
