# Аудит: Claude Code PRO (claude-code-pro-trainer)

Дата аудита: 2026-11-02. Метод: только чтение.

**1. Назначение.** Интерактивный тренажёр на русском по курсу justxor/claude-code-pro-course (MIT): 13 модулей, квизы, лабы, песочница, экзамен. Цель — платный продукт с аккаунтами и подпиской (`docs/PLAN.md`, утверждён 13.10.2026). Домена нет.

**2. Статус: Development.** Из 12 шагов плана сделаны 0–4 (CI, разделение контента, сервер, вход, синхронизация прогресса; PR #1–#5, 13.10). Шаг 5 (staging в РФ) не начат: нет Dockerfile, Caddyfile, прод-compose. Пользователей нет.

**3. Аудитория.** Русскоязычные разработчики, осваивающие Claude Code.

**4. Монетизация.** **Не реализована.** Платный контент `src/paid/*.js` собирается в ту же страницу, сервер отдаёт `dist/index.html` без проверки доступа (`server/app.ts`) — платные модули получает любой. План (`docs/PLAN.md`): CloudPayments (запасной ЮKassa), таблицы `subscriptions`, `payments`, `webhook_events`; бесплатно 00–03, платно 04–12. Цена, период, юрлицо и платёжка не решены.

**5. Стек.** Клиент — чистый JS, single-file `build.mjs`. Сервер — Node 24, Fastify 5, TypeScript; PostgreSQL 16 + Drizzle; Better Auth 1.7 (код на email, Яндекс, GitHub); nodemailer. Хостинг по плану — VPS в РФ, не развёрнут.

**6. Источники бизнес-данных.** `server/schema.ts`: `user` (email, createdAt, `pd_consent_at`, `pd_consent_version`), `session`, `account`, `verification`, `progress` (state, xp, mods_done) — для метрик вовлечённости. Подписок, платежей, LLM нет. Админ-отчётов нет.

**7. Состояние разработки.** 7 коммитов, 13.10.2026 — 26.10.2026 (PR #6, nodemailer); фактически работа шла два дня. Открытых PR и issues нет. Неудалённая смерженная ветка `claude/server-security-monitoring-poy04u`.

**8. Качество.** 4 тестовых файла (`test/smoke.cjs`, `content.test.mjs`, `server.test.mjs`, `answers.snapshot.json`). CI `ci.yml` (typecheck, build, test, test:server с Postgres), последний запуск зелёный (26.10). Линтера нет.

**9. Безопасность.** `sandbox/.env.lab` — учебный ложный секрет, намеренно. Реальных ключей нет. Репозиторий приватный. Платный контент открытым текстом в git — защищён только приватностью репозитория.

**10. Технический долг.** Платный контент не закрыт. Нет файла LICENSE с текстом MIT исходного курса (только ссылка в футере, `src/js/90-render.js:23`) — для MIT может не хватить (вывод). `better-auth: "1.7"` нестрогая. Неудалённая ветка.

**11. Риски (вывод).** Технические: платный контент без проверки доступа; ежемесячное списание не написано (риск двойных списаний); накрутка рейтинга. Бизнес: товарный знак «Claude» в названии; Claude официально недоступен в РФ — спрос ограничен; исходный курс бесплатен, 152-ФЗ и 54-ФЗ требуют юрлица.
