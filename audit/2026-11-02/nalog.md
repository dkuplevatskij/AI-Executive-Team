# Аудит: NAlog (nalog)

Дата аудита: 2026-11-02. Метод: только чтение — локальный клон, GitHub API.

**1. Название и назначение.** Калькулятор налогов при продаже недвижимости в РФ: мастер на 12 шагов, НДФЛ, вычеты, льготы, сравнение режимов ИП (CLAUDE.md, `client/src/lib/taxCalculator.ts`). Домен — `ainalog.pro` (`deploy/nalog.caddy`).

**2. Статус: Production (бесплатная версия).** Деплой при каждом push в `main` по SSH в `/opt/nalog` (`.github/workflows/deploy.yml`), последний успешный — 24.10.2026. Отдаётся общим Caddy (`infra-caddy-1`) на сервере RELTA, контейнер `nalog-app`. Данных о пользователях нет; подключена Umami (`client/index.html:44-45`), цифр в репозитории нет.

**3. Аудитория.** Физлица, ИП и риелторы, продающие недвижимость. В планах — тариф для агентств (`financial-model.html`).

**4. Монетизация.** Реализованы только заглушки: «Доступно после оплаты» (`PaidFeatureLocked.tsx`) на AI-анализе и PDF (`TaxResults.tsx:293-295`); сервер отказывает в AI-анализе (`AI_ANALYSIS_PAID_ONLY = true`, «Payments are not wired up yet», `server/routers/aiRouter.ts:6-7`). Провайдера нет. План (`financial-model.html`): Free, Pro 299 ₽/мес (2 870 ₽/год), «Агентство» 1 990 ₽/мес, Enterprise от 9 990 ₽/мес, ЮKassa/СБП. Внутреннее расхождение модели: «₽520К MRR на месяц 12» в шапке против 188 тыс. ₽ в таблице.

**5. Стек.** React 19, Vite 7, Tailwind 4, shadcn/ui, wouter; Express 4 + tRPC 11; Drizzle + MySQL 8.4; `@anthropic-ai/sdk` (`claude-sonnet-4-6`, выключен); DaData; Docker на Node 20; прокси к Anthropic/OpenAI на Cloudflare Worker (`nalog-ai-proxy/`, где развёрнут — нет данных); параллельно конфигурация Vercel.

**6. Источники бизнес-данных.** Одна таблица `users` (`drizzle/schema.ts`), вход удалён (PR #24), `user: null` всегда — таблица не наполняется. Подписок, платежей, учёта LLM нет. История расчётов — только localStorage. Единственный источник метрик — Umami. Вызовы DaData и Anthropic не логируются.

**7. Состояние разработки.** 81 коммит, 20.03.2026 — 24.10.2026; за 30 дней 9 (зависимости, сверка законодательства, удаление OAuth). PR 28, открытых 0; issues 0; релизов нет. Несмерженные ветки: `claude/epic-fermi-mpdc98` (05.10), `fix/dependency-vulnerabilities-20261012` (вероятно, заменена PR #27).
