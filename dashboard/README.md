# Дашборд AI Executive Team

Адрес: https://claude.ai/artifact/DU2nPFxCH2qJ59MWZJ6hkh (приватный — виден владельцу; поделиться можно из
меню Share на странице). Решение D-012.

## Что на нём
- **Сводка:** продуктов, платящих клиентов, ждут решения, задач в работе, задач в заданиях для сессий,
  действий, остановленных замком.
- **Лента команды:** решения собственника, материалы к решениям, отчёты, аудиты, задания для сессий —
  новые сверху, с фильтром; название ведёт на полный документ в GitHub.
- **Портфель, задания для сессий, задачи, согласования, действия агентов** — таблицы.

Источник правды — репозиторий. Дашборд только показывает данные, собранные скриптом
`tools/build_dashboard_data.py`. Страница — `dashboard/index.html` (тип Artifact «Dashboard»).

## Как обновить (делает AI CEO в конце каждой рабочей сессии)
1. `python3 tools/build_dashboard_data.py --out <папка в scratchpad> --ref <ветка>` — ветка, в которой лежат
   документы (после слияния PR — `main`), чтобы ссылки открывались.
2. Загрузить изменившиеся JSON в дашборд (`Artifact`, `asset: true`, `url` дашборда, по одному файлу).
3. Обновить у соответствующих наборов данных `source.url` и `updated` (`ArtifactData`, `update`
   документа `datasets/<id>` с `if_version`).
4. Если менялась страница — записать `dashboard/index.html` в документ `files/index.html` (`{text}`).
Наборы данных: `feed`, `portfolio`, `tasks`, `approvals`, `handoff`, `activity`.

## Уведомления в Telegram
Отправляет GitHub Actions — `.github/workflows/telegram-notify.yml` (скрипт `tools/notify_telegram.py`):
- новые отчёты, материалы к решениям, аудиты, задания для сессий, карточки согласования, задачи
  и решения в журнале — при push в любую ветку;
- PR открыт, готов к слиянию, слит или закрыт.

Нужны секреты репозитория `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (Settings → Secrets and variables →
Actions). Без них задание ничего не шлёт и не падает. Ключ бота в чат, файлы и журналы не попадает.
